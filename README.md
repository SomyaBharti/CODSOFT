# CodSoft Python Programming Internship

This repository contains the Python projects I developed as part of my **CodSoft Python Programming Internship**. These tasks helped me strengthen my programming fundamentals, problem-solving skills, and practical understanding of Python.

## 📌 Projects

### 1. To-Do List Application
A simple task management application that helps users organize and manage their daily tasks.

**Features:**
- Add new tasks
- View the task list
- Mark tasks as completed
- Delete tasks

**Technology:** Python

### 2. Calculator
A basic calculator built using Python to perform common arithmetic operations.

**Features:**
- Addition
- Subtraction
- Multiplication
- Division
- User input handling

**Technology:** Python

### 3. Password Generator
A Python application that generates random passwords to help users create stronger passwords.

**Features:**
- Generate random passwords
- Customize password length (if supported)
- Use a combination of letters, numbers, and special characters (if supported)

**Technology:** Python

## 🛠️ Technologies Used

- Python 3
- Python standard libraries
- Git and GitHub

## 🚀 How to Run

1. Install Python 3 on your computer.
2. Clone this repository:

   ```bash
   git clone https://github.com/SomyaBharti/CODSOFT.git
   ```

3. Navigate to the project folder:

   ```bash
   cd CODSOFT
   ```

4. Run any task using Python. For example:

   ```bash
   python Task1_ToDo.py
   ```

   ```bash
   python Task2_Calculator.py
   ```

   ```bash
   python Task3_Password_Generator.py
   ```
